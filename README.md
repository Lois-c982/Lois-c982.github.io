# Lois Coughlin — Portfolio

My personal portfolio website, showcasing my university projects,
experience and interests in Computer Science, UX and design.

I’m a Computer Science (UX + Design) student at the University of
Dundee and the Founder and President of the Women in STEM Society.

## About the website

I wanted a simple portfolio where people could explore my work and
learn more about me. The design is based on a layout I created in Canva,
with a monochrome colour scheme and large typography.

The website includes:

- An introduction and About section
- Project descriptions and screenshots
- My experience and skills
- A downloadable CV
- Email and LinkedIn links

## Projects

### Indago
A motivational self-care app concept for students. My work focused
on interface design, wireframes, Figma prototypes and accessibility.

### Excitare
A full-stack web application for alarm management, reviews and
Google Calendar integration. I worked on the frontend, usability
testing and API integration.

### Warehouse Management System
A database-driven project for managing products, suppliers and stock,
with a robot navigation module using A* search and a deep Q-network.

## Running locally

You will need Node.js installed.

Open a terminal in the project folder and run:

npm install
npm run dev

Open the local address shown in the terminal.

If the dependencies are already installed, you only need to run:

npm run dev

## Project files

- `src/main.jsx` — page content and React interactions
- `src/style.css` — styling and responsive layouts
- `public/` — project images and my CV
- `index.html` — the HTML entry point
